横浜ジュニアビレッジ プロジェクト探究

活動テーマ

自然、人、テクノロジーは、これからどんな関係をつくっていけばいいだろう？

私たちはいま、自然・社会・テクノロジーが大きく変化する時代に生きています。
便利になる一方で、環境問題や地域の課題など、さまざまな問いも生まれています。
プロジェクト探究コースは、農・食・アート・経済・テクノロジーなど多様な視点から、「自然と人はどう関わるべきか？」「テクノロジーはどんな未来をつくるのか？」
といった問いに向き合いながら、自分なりの答えを探究していきます。
正解はありません。五感を使った体験やプロジェクトを通して、
課題を整理する→情報を集め、比較し、考える→一度まとめて発表する→フィードバックを受け、もう一度考え直す、という探究のプロセスを、年間を通して何度も繰り返します。
このプロセスを繰り返すことで、すぐに答えを出すのではなく、深く考え、自分なりの納得解を導く力が育っていきます。

🌍 6つのテーマを横断する1年間のプログラム
自然：土の中の小さな英雄を観察しよう
農：野菜を育てて、味わって、フシギをみつけよう
食：売れるパッケージをデザインしよう
アート：子どもが耕す畑の魅力が伝わる〇〇をつくろう
経済：売り場をつくって、１円以上もうけよう
テクノロジー：テクノロジーを使ったアイディアでプロトタイプをつくろう

これらのプログラムを体験していくなかで、自分の興味をぐっと掘り下げ、「自分だけの探究テーマ」を見つけていきます。
実際のフィールドに出て、人と出会い、“やってみる”をくり返す中で、子どもたちは自分の問いを育て、世界とのつながりを実感していきます。

︎🌱プロジェクト探究コースが大切にしていること︎🌱
①正解のない問いに向き合い、深く考えること
このコースでは、答えが用意された問題には取り組みません。
自然や地域、社会に実際に触れながら、 正解のない問いをどう捉え、どう考えるかを大切にしています。
すぐに答えを出すのではなく、 立ち止まり、考え、試し、考え直す。
その積み重ねが、思考の深さを育てます。

②五感を使い、実社会とつながること
学びの舞台は、実社会そのものです。見て、触れて、感じて、試す。
五感を使った体験があるからこそ、学びは机上の空論ではなく、自分ごととして深まっていきます。

③一人ひとりの「関心の芽」を尊重すること
最初から「これが好き」「これが得意」がなくても大丈夫です。
さまざまなテーマに触れ、試す中で、自分でも気づいていなかった関心の芽が見えてきます。
プロジェクト探究コースは、その芽を急がせず、比べず、その子のペースで育てていくことを大切にしています。

Coach

大竹千広

グローカルデザインスクール、寺子屋根っこ塾創業者。地域体験・経験学習プロデューサー。アグリアーツ®︎カリキュラム開発者。国家資格キャリアコンサルタント。青山学院大学国際政治経済学部卒業後、JTBにて2021年3月まで勤務。2010年に、旅・体験を通じた子ども達の豊かな成長を手助けする「旅いく」を社内新規事業として創業。お茶の水女子大学と共同で「地域で異年齢の子ども達が体験することにより育まれる力」を研究し、子ども達の好奇心、探究心を刺激する体験型学習プログラム開発や子ども達の体験活動に伴走する人材研修に14年携わる。今まで1000以上の学習型体験商品を開発し、10万人以上の子どもたちの活動に関わっている。横浜ジュニアビレッジ根っこ塾では、自称「用務員」として、大学生や地域の大人達と共に子ども達の見守り役をしている。2児の母。

「木かふぇ・木風心風堂」
横浜市営地下鉄センター北駅から徒歩15分。一流を育てる職人集団秋山木工がプロデュースする「木風心風堂」は「まちの寺子屋」です。木工、彫刻、パステル、書道、食、花など 　さまざまなテーマで、ものづくりを通じて日本の心に触れ、「夢中になれる場所」として、日本中から大人も子どもも訪れています。木のぬくもりを感じる空間で、子どもたちは集中して活動参加することができます。
